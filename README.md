# Aluga Facil

Sistema web para cadastro e exibicao de imoveis para aluguel.

## Objetivo

O projeto atende dois perfis principais:

- Locador: cadastrar, editar e publicar imoveis para aluguel.
- Inquilino: visualizar imoveis disponiveis e filtrar por cidade, tipo, preco e caracteristicas.

## Como executar

Abra o arquivo `index.html` no navegador.

Como a primeira versao apenas para teste de conhecimento trata-se de uma aplicacao estatica, nao ha instalacao de dependencias obrigatoria.
