# Aluga Facil

Sistema web para cadastro e exibicao de imoveis para aluguel.

## Objetivo

O projeto atende dois perfis principais:

- Locador: cadastrar, editar e publicar imoveis para aluguel.
- Inquilino: visualizar imoveis disponiveis e filtrar por cidade, tipo, preco e caracteristicas.

## Como executar

Abra o arquivo `index.html` no navegador.

Como a primeira versao e uma aplicacao estatica, nao ha instalacao de dependencias obrigatoria.

## Padrao de commits

Os commits devem ser feitos por blocos de funcionalidade, mantendo historico facil de revisar.
