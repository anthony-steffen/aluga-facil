AF Aluga Facil
Projeto Front-end

Case de produto

Sistema para aluguel de imóveis em Aparecida de Goiânia

Uma aplicação web para conectar locadores e inquilinos com uma experiência simples, moderna e focada no mercado local.

01 Problema

O desafio

Buscar imóvel ainda costuma ser confuso.

! Informações espalhadas Dados de preço, bairro e características nem sempre aparecem de forma clara.
? Cadastro sem padrão Locadores precisam organizar detalhes para apresentar melhor seus imóveis.
# Busca pouco local O usuário precisa enxergar opções que façam sentido para sua região.
02 Solução

A proposta

Dois fluxos principais no mesmo produto.

I Inquilino Visualiza imóveis disponíveis, filtra por cidade, tipo, valor máximo e busca textual.
L Locador Cadastra, edita e remove imóveis com dados estruturados e imagem de destaque.

Menos atrito para anunciar. Mais clareza para decidir.

03 Interface

Experiência visual

Layout moderno, responsivo e direto ao ponto.

100% front-end funcional, sem dependências obrigatórias para rodar a primeira versão.
04 Funcionalidades

O que foi implementado

Um MVP navegável e demonstrável.

F Filtros de busca Cidade, tipo, preço e termo livre para encontrar imóveis rapidamente.
C Cadastro completo Título, bairro, cidade, tipo, preço, quartos, banheiros, foto e descrição.
E Edição e exclusão Gestão dos imóveis cadastrados pelo locador direto na interface.
05 Localização

Contexto regional

Dados pensados para Aparecida de Goiânia.

Garavelo Apartamento completo com garagem e boa oferta de serviços.
Vila Brasília Casa ampla próxima ao Aparecida Shopping.
Nova Era Studio funcional perto do Buriti Shopping.

Como desenvolvi

Entrega organizada por blocos de funcionalidade.
